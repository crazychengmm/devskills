## 新暴露问题（已回灌 v0.5）

1. **p3c 版本兼容暗坑**：p3c-pmd 2.1.1 是 PMD6 内核，maven-pmd-plugin 3.21+ 默认 PMD7 不兼容；ruleset 文件是 ali-flowcontrol.xml。
   → 新增 `references/standards/java-p3c-setup.md`（验证过的版本矩阵、完整 pom 片段、review 用法），code.md/common.md 链接过去。
2. **第三方 API 凭记忆写错 3 次**（TokenRange.getLine、JavaToken.line、VariableDeclarator 包路径）。
   → code.md 工具链预检增加「Java API 先 javadoc/javap 查实」纪律。
3. **依赖版本凭直觉有风险**（插件与规则包大版本必须配套）。
   → code.md 增加「版本先查 Maven Central metadata」与首次构建超时提示。
4. **工具类项目缺自举验收**。
   → test.md 新增第 5 节：工具必须能处理自身代码，失败按正常缺陷回 code。
