## 新暴露的问题（已回灌 v0.3）

1. **CLI 脚手架非原子**：`openspec new change --goal"文本"`（flag 与值间漏空格）建出无 `.openspec.yaml` 的半成品目录，重试报 already exists。
   → openspec-cheats.md 与 analyze.md 增加：长 flag 值必须空格分隔、创建后立即校验元数据文件存在、半成品的处理办法。
2. **机械检查靠人记得**：虽然每任务都执行了，但命令每次靠手打。
   → common.md 顶部增加「机械化检查一行命令」（Python/Go/Java 可直接粘贴），code.md 自检步骤引用它。
3. **实现/测试提交粒度无明文**：本次自发分开但规程没写。
   → commit.md 固化为推荐粒度，双向核对按任务号聚合。
