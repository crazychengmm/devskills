# 领域术语表（统一语言 Ubiquitous Language）

> 访谈/开发过程中持续演进，**当场对齐而非事后补**。spec、code（类名/变量/表列）、日志、review 共用本表词汇；同物异名、同名异物在这里解决。

| 术语 | 英文/代码名 | 一句话定义（业务语言） | 易混淆词（不要混用） | 备注 |
|---|---|---|---|---|
| 子网 | subnet | 一个 CIDR 表示的二层/三层地址块 | 网段、VLAN | |
| 分配 | allocation | 把子网内一个 IP 绑定给使用方的记录 | 占用、申请 | |
| 回收 | release | 释放分配，地址可被再次使用 | 删除 | 分配记录删除但业务含义是释放 |
